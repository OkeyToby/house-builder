# Assets

Læg alle eksterne assets her, så projektet er organiseret og nemt at vedligeholde.

## Struktur

- `assets/models/` 3D-modeller (FBX, OBJ, RBXM, osv.)
- `assets/textures/` teksturer/materialer (PNG, JPG, osv.)
- `assets/sounds/` musik og lydeffekter
- `assets/ui/` ikoner, UI-grafik, fonts
- `assets/licenses/` licenser og kilder for hver asset

## Regler

1. Brug konsistente filnavne: `kategori_navn_variant.ext` (fx `tree_oak_01.fbx`).
2. Gem altid licensinfo i `assets/licenses/`.
3. Hold en ens stilart (samme kvalitet/farver) på tværs af assets.
